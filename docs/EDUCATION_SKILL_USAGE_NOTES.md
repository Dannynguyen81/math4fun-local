# Ghi chú áp dụng Education Agent Skills

Education Agent Skills là thư viện 165 skill dựa trên nghiên cứu, có thể dùng cục bộ bằng cách sao chép từng thư mục chứa `SKILL.md`; không cần MCP hosted, token hoặc dependency. Để tránh làm môi trường quá tải, Math4Fun chỉ nên cài các skill cụ thể liên quan đến luồng đăng ký/onboarding: giảm tải nhận thức, phản hồi học tập, động lực/agency và gợi ý thích ứng.

Khi áp dụng vào Math4Fun, các nguyên tắc giáo dục phải phục vụ học sinh tiểu học: form đăng ký ngắn, công bố dần thông tin, lời nhắc rõ ràng bằng tiếng Việt, không dùng lựa chọn áp đảo, và mọi hiệu ứng game chỉ củng cố việc học thay vì tạo áp lực. Không dùng MCP hosted hoặc chia sẻ thông tin học sinh cho bên thứ ba.
